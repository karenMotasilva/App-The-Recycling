## 🌱 Sobre o projeto

O **The Recycling** é um aplicativo que busca incentivar hábitos sustentáveis por meio da gamificação. A proposta é tornar a reciclagem mais interativa, permitindo que os usuários acompanhem seus pontos, visualizem sua posição no ranking e conheçam recompensas.

O projeto foi desenvolvido como parte de uma experiência acadêmica em equipe, unindo desenvolvimento mobile, design e sustentabilidade.

## ✨ Funcionalidades

- Cadastro e login de usuários
- Visualização de pontos
- Ranking de participantes
- Catálogo de recompensas
- Histórico de pontos e recompensas
- Perfil do usuário

> Atualize esta lista conforme as funcionalidades forem implementadas no aplicativo.

## 🚀 Como executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/karenMotasilva/App-The-Recycling.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd App-The-Recycling
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie o Expo:

   ```bash
   npx expo start
   ```

Siga as instruções exibidas no terminal para executar o aplicativo no emulador ou dispositivo.
