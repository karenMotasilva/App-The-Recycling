🌱 Sobre o projeto

O The Recycling é um projeto desenvolvido com o objetivo de incentivar práticas sustentáveis por meio de uma experiência interativa.

A proposta é permitir que os usuários acompanhem seus pontos, participem de rankings e troquem suas conquistas por recompensas, tornando a reciclagem mais acessível e motivadora.

Mais do que descartar resíduos, queremos incentivar uma mudança de hábito.

✨ Funcionalidades

- Cadastro e autenticação de usuários
- Sistema de pontuação por reciclagem
- Ranking de participantes
- Catálogo de recompensas
- Histórico de pontos e resgates
- Perfil do usuário
- Incentivo à participação sustentável
